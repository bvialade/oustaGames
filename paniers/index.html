Chacun son panier

  • Chaque zone de couleur est un panier : installe un chat dans chaque panier.
  • Il faut aussi un seul chat par ligne et par colonne.
  • Les chats veulent dormir tranquilles : deux chats ne se touchent jamais, même en diagonale.
  • Touche une case une fois pour une croix (« pas de chat ici »), deux fois pour un chat, trois fois pour la vider. Glisse le doigt pour poser plusieurs croix d'un coup.
  • ✖️ Croix auto marque d'un point les cases interdites par les chats déjà posés.
  • 🌿 Herbe à chat installe un bon chat (3 par grille).
